# Third-party assistant marks

The Connect your AI cards show a 24 px mark next to each assistant name. Those files live in `assets/assistant-logos/` and are bundled into the extension. They are never loaded from the network.

Bobbin is not affiliated with, endorsed by, or sponsored by these companies. Their names are used only to describe compatibility.

## Why the cards use lettered tiles

Each company's public brand or press page was checked before shipping. None of them grant a license to put their official logo on a third-party Chrome extension's compatibility cards:

| Assistant | Brand / press page checked | Usage terms that block this use |
| --- | --- | --- |
| Claude | https://www.anthropic.com/news and https://www.anthropic.com | Anthropic's public materials do not license the Claude mark for third-party product UI. |
| ChatGPT | https://openai.com/brand | OpenAI's brand guidelines restrict logo use that could imply partnership or endorsement. |
| Gemini | https://about.google/brand-resource-center/ | Google does not allow third parties to use Google or Gemini logos without permission. |
| Grok | https://x.ai | xAI does not publish a license for third-party product cards. |
| Muse | https://muse.ai | No public third-party logo license was found. |
| Perplexity | https://www.perplexity.ai and https://www.perplexity.ai/hub | Press and product marks are not licensed for third-party extension UI. |
| Other | (none) | Neutral tile for any other assistant. |

## What ships

Each file is an original 24×24 SVG: a rounded square and a letter (or "+"), drawn for Bobbin. They are not copies, traces, or color-matched recreations of any company's logo.

| File | Tile |
| --- | --- |
| `claude.svg` | C |
| `chatgpt.svg` | GPT |
| `gemini.svg` | Ge |
| `grok.svg` | X |
| `muse.svg` | M |
| `perplexity.svg` | P |
| `other.svg` | + |

If a company later grants written permission for this use, that assistant's official unmodified logo can replace its tile here, still bundled locally.
